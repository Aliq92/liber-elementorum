# Icon & splash sources

Hand-authored SVG, not generated by any external tool: a compass/star rune
(matching the app's own Ignis-top / Aqua-right / Terra-bottom / Aeris-left
button layout) on a dark violet radial gradient.

- `icon-source.svg` — combined flat icon (legacy `ic_launcher.png` / `ic_launcher_round.png`,
  and the source for the PWA manifest icons below)
- `icon-foreground.svg` — adaptive icon foreground layer (transparent background)
- `icon-background.svg` — adaptive icon background layer (gradient only)
- `splash-source.svg` — splash screen, square master
- `play-store-icon-512.png` — 512×512 flat icon for the Play Store listing

`icon-source.svg` already has a full-bleed background and keeps the rune well
inside a safe zone (outer ring radius 330 of a 512 half-width — comfortably
inside the ~40%-radius maskable safe circle), so it doubles as the source for
the PWA manifest's `icons/icon-*.png` ("any") and `icons/maskable-*.png`
("maskable") entries — see `../manifest.webmanifest` and `../icons/`. No
separate maskable artwork was needed.

## Regenerating

There's no image-editing dependency required — everything is rasterized with
a `<canvas>` in a real browser, since headless SVG rasterizers (cairosvg
etc.) need native libraries this project doesn't otherwise depend on.

1. Serve the project root (`python serve.py`) and open
   `http://localhost:5173/icon-source/rasterize.html` in a browser.
2. In devtools console: `await rasterizeAll()` renders every density variant
   to canvas; `await uploadAll()` POSTs each one to a local receiver.
3. Run `python icon-source/receiver.py` first (listens on `127.0.0.1:5180`)
   so step 2 has somewhere to send the files — it decodes and writes them to
   `icon-source/out/`, keeping the (large) image bytes out of any chat
   context instead of returning them as text.
4. Copy the results from `icon-source/out/` into
   `android/app/src/main/res/` — mipmap-* for the launcher icon,
   `drawable*/splash.png` for the splash (see the exact filenames/sizes in
   `rasterize.html`, which mirrors Capacitor's default template layout).
   Copy `icon-source/out/icons/*.png` to `../icons/` for the PWA manifest.
